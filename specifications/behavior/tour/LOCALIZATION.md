# Voyant 旅行团活动本地化规则

## 原则

- Voyant fork 是旅行产品、团期、名额、预订、行程、价格和退款功能基线。
- 各 Voyant UI 包使用统一中文术语，不分别创造含义不同的译名。
- 中文只改变显示文本，不改变产品、库存、预订、价格或财务规则。
- 中文资源直接维护在tuyutata/voyant Fork中，随Voyant Web界面构建；不在Flutter中复制旅行团业务页面。
- 默认语言为简体中文，英文继续支持；未支持的系统语言回退简体中文。
- 当前核心管理员导航和认证文本已提供中文，尚未翻译的上游扩展文本回退英文并在后续翻译清单中处理。

## 核心术语

| 上游术语 | 简体中文 |
|---|---|
| Product | 旅行产品 |
| Departure | 团期 |
| Availability | 可售名额 |
| Capacity Bucket | 名额池 |
| Inventory Hold | 名额保留 |
| Booking | 预订 |
| Participant | 参与人 |
| Itinerary | 行程 |
| Itinerary Day | 行程日 |
| Price Plan | 价格方案 |
| Refund | 退款记录 |

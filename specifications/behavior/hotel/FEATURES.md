# 酒店及酒店餐厅功能清单

## 第一阶段必须迁移

- 酒店、房型、房间、图片、设施和房态。
- 房价、季节价、价码、餐食计划、优惠、价格护栏和受控超售。
- 散客、多房、团队、企业及旅行代理预订。
- 入住人、入住、换房、延住、退房、取消和未到店。
- Folio、费用、收款状态、押金、拆分、转移和冲正。
- 房务任务、失物招领、服务工单和交接班。
- 酒店餐厅档口、桌台、菜单、配方、库存、POS、KOT 和客房挂账。
- 夜审、入住率、ADR、RevPAR、收入和收款报表。
- 酒店管理员、前台、财务、收益、房务和餐饮内部岗位。

## 后续迁移

- 宴会、场地、渠道管理、第三方消息、MCP、AI 助手和国家税务包。
